# Contributor Instructions

## Documentation

- Keep `README.md` (English) and `README.zh.md` (Simplified Chinese) synchronized.
- Keep `docs/en/*.md` (English) and `docs/zh/*.md` (Simplified Chinese) synchronized whenever audit fields, event contracts, configuration, or deployment behavior changes.
- A documentation change must update both languages in the same commit.
- Before finishing documentation or interface work, compare the corresponding Chinese and English sections and verify that field names, defaults, privacy guarantees, and examples match.
